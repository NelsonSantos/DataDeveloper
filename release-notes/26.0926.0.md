# Release Notes — 26.0926.0

## Summary
- Connection and query tabs can now be reordered and pulled into their own windows, and each query keeps its own collapsible results panel.
- Ctrl+Tab switches between recently used queries, with a switcher that lists your open connections and queries.
- Panel sizes (Schema Explorer width, results height) and whether they are collapsed are remembered per connection and per query.
- The app keeps running when the database becomes unreachable, for example when the VPN drops, and tells you what happened.
- On macOS, the Dock icon menu lists your open and recent connections, plus New query and Load/Add connection.
- On macOS and Linux, app data moves out of the Documents folder to the standard location, automatically.
- Built on .NET 10 and Avalonia 12, with faster, type-checked UI bindings.

## What's new
- **Dockable workspace** — connection and query tabs use [Dock](https://github.com/wieslawsoltes/Dock): drag tabs to reorder them, float a query into its own window, and use the tab list button when there are more tabs than fit. Results live inside each query and reopen when you run it. ([#60](https://github.com/NelsonSantos/DataDeveloper/pull/60), [#68](https://github.com/NelsonSantos/DataDeveloper/pull/68))
- **Query switcher** — Ctrl+Tab follows recent use, like Rider and VS Code. A quick Ctrl+Tab goes back to the previous query; holding Ctrl shows every open connection (numbered 1–9) and its queries. ([#61](https://github.com/NelsonSantos/DataDeveloper/pull/61))
- **Remembered layout** — the Schema Explorer width and each query's results height, and whether they are collapsed, are restored when a connection reopens. ([#66](https://github.com/NelsonSantos/DataDeveloper/pull/66))
- **macOS Dock menu** — right-click the Dock icon to switch to an open connection, reopen one of the last five connections, start a new query or open the connection selector. ([#69](https://github.com/NelsonSantos/DataDeveloper/pull/69))

## Fixes
- **Lost connections no longer close the app** — errors such as a dropped VPN are logged to `logs/errors.log` and shown in a dialog; autocomplete waits 30 seconds before trying an unreachable database again. ([#62](https://github.com/NelsonSantos/DataDeveloper/pull/62))
- **App data location on macOS and Linux** — data now lives in `~/Library/Application Support/DataDeveloper` (macOS) and `~/.config/DataDeveloper` or `$XDG_CONFIG_HOME` (Linux) instead of under `~/Documents`. Existing data is moved on first launch; nothing is overwritten, and passwords are unaffected. ([#70](https://github.com/NelsonSantos/DataDeveloper/pull/70))

## Under the hood
- .NET 10 ([#57](https://github.com/NelsonSantos/DataDeveloper/pull/57)), Avalonia 12.1 and ReactiveUI 24 ([#58](https://github.com/NelsonSantos/DataDeveloper/pull/58)), compiled bindings across all views ([#59](https://github.com/NelsonSantos/DataDeveloper/pull/59)).
- Npgsql 9.0.5 ([#67](https://github.com/NelsonSantos/DataDeveloper/pull/67)); removed the obsolete PostgreSQL `TrustServerCertificate` option with no behavior change ([#65](https://github.com/NelsonSantos/DataDeveloper/pull/65)).
- Every pull request is now built and tested on Linux, Windows and macOS ([#63](https://github.com/NelsonSantos/DataDeveloper/pull/63)); the local build scripts no longer require `VERSION` on macOS ([#64](https://github.com/NelsonSantos/DataDeveloper/pull/64)).
