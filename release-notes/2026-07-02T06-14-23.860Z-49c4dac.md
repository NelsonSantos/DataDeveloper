## Summary
- Add Create/Edit Table Designer feature across all providers
- Adds a full Table Designer for creating and editing tables — columns, primary keys, foreign keys, indexes, and provider-specific index options (SQL Server clustered/fill factor, PostgreSQL index method/partial-index `where`, MySQL index prefix length) — accessible from the schema explorer's "New table..." / "Edit table..." context menu entries.
- Provider-aware DDL generation for all 5 supported databases (SQL Server, MySQL, PostgreSQL, Oracle, SQLite), including add/drop column, alter column type/length/precision/scale/nullable/default, rename column/table, and add/drop primary key/foreign key/index.
- SQLite gets a full rebuild procedure (temp table + copy + drop + rename, wrapped in `pragma foreign_keys=off/on`) for the diffs it can't express via `ALTER TABLE`.
- Destructive changes (drops) show an itemized confirmation dialog before applying; edit-table statements run inside an explicit transaction.
- Fixes an unrelated crash: `TabDataGridViewModel.LoadNextPage` now catches generic exceptions instead of only `OperationCanceledException`, preventing an unhandled `SocketException` from crashing the app during pagination.
- Renames `AGENTS.md` → `CLAUDE.md` throughout the repo and adds a Git safety rule requiring a `feature/<name>` branch for every change (no direct commits to `main`).
