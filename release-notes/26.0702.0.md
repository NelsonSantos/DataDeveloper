# Release Notes — 26.0702.0

## Summary
- **New: Create/Edit Table Designer**, available for all supported databases (SQL Server, MySQL, PostgreSQL, Oracle, SQLite):
  - Create a new table or edit an existing one from the schema explorer ("New table..." / "Edit table..."), with a full UI for columns, primary keys, foreign keys, and indexes.
  - Provider-specific index options: SQL Server clustered index + fill factor, PostgreSQL index method and partial-index `where` predicate, MySQL index prefix length.
  - Edit an existing table's column type, length, precision, scale, nullability, and default, or rename a column/table.
  - SQLite changes that can't be expressed with `ALTER TABLE` are applied via a safe rebuild (temporary table + copy + swap), preserving existing data.
  - Destructive changes (dropping a column, key, or index) show an itemized confirmation before being applied.
- Fixed a crash where an unexpected data error while scrolling a result grid (e.g. a dropped connection) could close the app; it now shows an error message instead.
